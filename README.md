# Капитан Пятёрочка

Вертикальный shoot 'em up для Telegram Mini App.

## Играть

- Превью: открой бота в Telegram и нажми кнопку меню
- Веб: https://helmut010306.github.io/kapitan-pyaterochka/

## Подключить к Telegram (BotFather)

1. Открой [@BotFather](https://t.me/BotFather)
2. `/newbot` — имя `Капитан Пятёрочка`, username например `pyaterochka_force_bot`
3. `/newapp` — выбери бота
4. Title: `Капитан Пятёрочка`
5. Description: `Оборона складов сети. 10 миссий, баллы Апельсина.`
6. Фото: `public/bot-cover.jpg` (640×360)
7. GIF: `/empty`
8. URL:
   `https://helmut010306.github.io/kapitan-pyaterochka/`
9. Short name: `game`
10. `/setmenubutton` — тот же URL, текст `В БОЙ`

Ссылка для игроков: `https://t.me/<bot_username>/game`
